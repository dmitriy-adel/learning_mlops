## ТЗ

- Создать backend-приложение, которое хранит и возвращает данные о товарах, используя PostgreSQL для хранения и Redis для кэширования, и полностью управляется через Docker Compose.

1. API (FastAPI/Flask)

    - GET /products — возвращает список товаров.

    - POST /products — добавляет новый товар с полями id, name, price.

    - GET /products/{id} — возвращает товар по id.

    При запросе GET /products сервис сначала проверяет Redis:

        - Если данные есть в кэше → вернуть оттуда.

        - Если данных нет → взять из PostgreSQL, положить в Redis на 60 секунд и вернуть.

2. Docker Compose

    - Создать docker-compose.yml, который поднимает три сервиса:

        1. api — твой backend.

        2. db — PostgreSQL.

        3. cache — Redis.

    - Настроить сети, чтобы сервисы могли общаться между собой (api → db, api → cache).

    - Настроить переменные окружения для db и cache (логин, пароль, хост, порт).
