## ТЗ

- Создать систему из двух api: service_reciever и service_processor.
    - service_reciever принимает запрос от пользователя с текстом и указанием, что подсчитать (символы или цифры), передаёт задачу в service_processor, получает от него же результат и возвращает его пользователю.

    - service_processor выполняет подсчёт (количество символов или цифр в строке) и возвращает результат.

    Оба сервиса должны быть упакованы в Docker-контейнеры и доступны для запросов с localhost.

## Пайплайн билда и запуска апи

1. билд контейнеров с api: 

    ```bash
    cd docker-compose
    sudo docker compose build
    ```

2. подъем контейнеров:

    ```bash
    sudo docker compose up
    ```

## Что понял

-  использование docker-compose и правда сильно упрощает работу со множеством контейнеров
